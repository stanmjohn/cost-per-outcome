# Cost per outcome: Ferncastle Skills Year (made up), counted in jobs

> **PLACEHOLDER. This program is made up.** A real file would use the program's own cost per person and an employment result from a lottery study or another study with a comparison group.

One outcome is one added person employed five years later · A made-up city · One class, followed for five years

## The read

One added person employed five years later costs about **$1,140,000** in the middle run. Eight runs in ten come in above **$424,000**. **The high end has no finite answer**, because in 22 percent of 20,000 runs the program added nothing beyond what happens without it.

The assumption that moves the answer most is **share of people employed because of the program, year five**. That is where the next research dollar goes.

## The bare number, and why it is not the answer

Budget cost divided by the gross result gives **$23,400** for one added person employed five years later. That figure credits the program with everything that happened to its participants, including what happens with no program at all. It has no range and no comparison. It is printed here once, only to be set beside the read above.

## The four questions

**What happens without the program.** The file takes the added result straight from a study with a comparison group: 1.5% likely, -3% to 6%.

**Where the cost line falls.** Cost per participant is $17,000 at the likely values, in current dollars. $3,000 of that, 14 percent of the full cost, sits outside the program's own budget. The file subtracts $4,000 in costs the comparison group ran up elsewhere.

**How long the result has to last.** Measured at: The fifth year after the lottery. The file gives no share still holding the result, so the tool took it as 100 percent. If results fade, the true cost is higher.

**How good the count is.** Counted by: State wage records for a program group and a comparison group picked by lottery (made up). The file gives no count check, so the tool took the count at face value.

## How the range was made

Each assumption above was drawn 20,000 times from a triangle-shaped spread that never goes below its low or above its high and lands most often near its likely value. Each run computes cost per participant divided by the result the program added per participant. The middle run is the median. The range is the 10th to the 90th percentile. The seed is 20260917, so the same file gives the same brief on any machine.

## What this brief refuses to do

It never prints a cost per outcome without a range. It never compares this program to another one, because two programs rarely count the same outcome the same way. It never projects past the years the evidence covers. It never uses a benchmark without naming it and its source.
